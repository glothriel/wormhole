### Task 02: Add `AppStateChangeGenerator.RemovePeer`

**Goal:** Let the server withdraw every app a peer last synced and forget that peer's app list, so its exposure is removed and a re-paired peer with the same name gets its apps exposed again.

**Context:**
- Overall approach for issue #102: `syncing.Server.DeletePeer` (task 03) calls `RemovePeer` while holding the server's sync mutex, after the peer record and metadata are deleted.
- `pkg/syncing/appstate.go`: `AppStateChangeGenerator` keeps `peerApps map[string][]apps.App` (last synced apps per peer, already patched with `Peer`), guarded by `lock sync.Mutex`, and sends `svcdetector.AppStateChange{App, State}` on the unbuffered `changes` channel. `UpdateForPeer` sends `svcdetector.AppStateChangeWithdrawn` for removed apps and logs `logrus.Infof("App %s.%s removed", app.Peer, app.Name)`.
- On the server, `changes` is consumed by `listeners.Registry.Watch` (`pkg/listeners/exposer.go`), which calls `Exposer.Withdraw` and drops the app from the list behind `GET /api/apps/v1` (matching on both `Name` and `Peer`). Withdraw failures are logged there and the app is still dropped. Do not change `Registry.Watch`.
- Rule: `RemovePeer` sends the withdraw events while holding `s.lock`, in the order of the stored slice, then deletes the map entry. A peer without an entry produces no events and does not block.
- Rule: other peers' entries in `peerApps` are untouched.
- Tests read events from `Changes()` in the test goroutine and drive the generator from a second goroutine, because the channel is unbuffered.

**Acceptance criteria:**
- [ ] `RemovePeer(p)` emits one `AppStateChangeWithdrawn` per app `p` last synced, and none for other peers.
- [ ] After `RemovePeer(p)`, a new `UpdateForPeer(p, apps)` emits `AppStateChangeAdded` for each app again.
- [ ] `RemovePeer` for a peer that never synced returns without emitting anything.

**Changes:**
- `pkg/syncing/appstate.go` — add, after `UpdateForPeer`:
  ```go
  // RemovePeer withdraws all the apps last synced by the peer and forgets the peer
  func (s *AppStateChangeGenerator) RemovePeer(peer string) {
  	s.lock.Lock()
  	defer s.lock.Unlock()
  	for _, app := range s.peerApps[peer] {
  		logrus.Infof("App %s.%s removed", app.Peer, app.Name)
  		s.changes <- svcdetector.AppStateChange{
  			App:   app,
  			State: svcdetector.AppStateChangeWithdrawn,
  		}
  	}
  	delete(s.peerApps, peer)
  }
  ```
